How this academy works

One real Python runtime, in your browser. Code cells run on Pyodide (Python compiled to WebAssembly). Nothing is installed on your computer.

  • Run ▶ executes the code in a cell. Variables persist between cells, just like a notebook. Restart kernel wipes them.
  • Check my work on an exercise runs hidden tests; you'll get a specific message when something is off.
  • Quizzes are marked instantly; pass at 70% or better to complete the item.
  • Your progress, notes, and checklist state are saved in this browser (localStorage).

Keyboard: Ctrl+Enter runs the cell you're editing.

Reset progress?

This clears completed exercises, quiz scores, saved notes, and checklists on this device. It cannot be undone.
